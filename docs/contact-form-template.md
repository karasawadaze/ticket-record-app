# ライブ記録 お問い合わせフォーム設計

Googleフォームを作る場合は、以下の項目で作成してください。

## フォームタイトル

ライブ記録 お問い合わせ

## 説明文

ライブ記録アプリへのお問い合わせフォームです。不具合報告の場合は、端末名・OSバージョン・操作手順もわかる範囲で記入してください。

## 質問項目

1. お問い合わせ種別
   - 形式: ラジオボタン
   - 選択肢: 不具合報告 / 機能要望 / データ・プライバシーについて / その他
   - 必須: はい

2. お名前
   - 形式: 記述式
   - 必須: いいえ

3. メールアドレス（返信が必要な場合のみ）
   - 形式: 記述式
   - 必須: いいえ

4. お問い合わせ内容
   - 形式: 段落
   - 必須: はい

5. 端末・OSバージョン
   - 形式: 記述式
   - 必須: いいえ

6. アプリバージョン
   - 形式: 記述式
   - 必須: いいえ

7. 返信について
   - 形式: チェックボックス
   - 選択肢: 返信が必要です
   - 必須: いいえ
